一眼看懂：這支影片最重要的 10 點

  1. 好的學習歷程可以直接長在課程裡，不需要另外硬做。
    課程從軟體操作、選題、探究、分組討論、成果發表、同儕回饋到報告書，本身就形成完整學習軌跡。

  2. 專題的價值不只在答案，而在整個「解題過程」。
    遇到什麼困難、怎麼查資料、怎麼改方向、怎麼驗證，比最後答案更能看出能力。

  3. 額外自學會形成很強的能力證據。
    優良作品中，學生額外學了 Overleaf、LaTeX、課外數學知識與程式驗證，讓作品明顯超過課堂最低要求。

  4. 完整心路歷程可以增加作品的可信度。
    從誤判題型、遇到瓶頸，到找到方法解決，能讓讀者感覺這確實是學生自己做的。

  5. 工具不必被課程限制。
    課堂用 GeoGebra 只是入口；真正解題時可以加入程式、其他軟體或不同方法，只要能合理支持研究。

  6. 原創性會影響後續延伸空間。
    老師認為案例作品最大的可惜，是題目不是原創，因此較難繼續延伸成科展、小論文或長期研究。

  7. 「沒有時間」本質上是優先順序與時間管理問題。
    如果真的認為這份作品重要，就要主動排出時間，而不是等到學期末才開始。

  8. 遇到太難的內容，要主動求助。
    可以查資料、找校內外老師，甚至主動寫信給大學教授；重點是清楚說明「我是誰、在做什麼、卡在哪裡、我已經努力到哪一步」。

  9. 不知道做什麼題目，可以從閱讀與生活觀察找問題。
    一個太大的問題可以加條件縮小；一個小問題也可以放寬條件，逐步變成可研究的題目。

  10. 學習歷程最後仍要讓人快速讀懂你是什麼樣的人。
    精簡、圖像化、反思前置、邏輯完整、美編適度、校稿無錯字，並讓作品呈現你的態度、解題方式與自主學習能力。

課程設計本身就是一個專題流程

陳珮如老師的課程大致是：

基礎工具 → 主題探索 → 小組討論 → 實作 → PPT／報告書 → 上臺發表 → 同儕回饋 → 最終成果

學生在這個過程同時練習： - 數學軟體操作 - 專題探究 - 課外自學 - 問題解決 - 團隊合作 - 溝通 - 口語表達 - 書面報告

核心觀念：學習歷程不是「課程結束後才做」，而是把課程中已經發生的學習整理出來。

優良案例：四平方和定理

案例的幾個亮點：

1. 專業呈現

學生額外學習： - Overleaf - LaTeX

讓報告具有接近學術論文的清楚格式。

2. 課外數學自學

題目需要超過高中課內內容的知識，因此學生必須主動補足背景。

3. 完整呈現困難與解決

不是只說「我們成功了」，而是呈現：

一開始怎麼想 → 發現方向不對 → 遇到什麼障礙 → 怎麼調整

4. 用程式驗證數學

不限制只使用 GeoGebra；學生可以用自己會的工具驗證與解決問題。

案例可再改進之處

  • 題目並非原創。
  • 因課程時間有限，選題速度較快。
  • 課程結束後沒有繼續深入延伸。
  • 若一開始找到更有原創性的問題，高二可以接續自主學習，甚至延伸科展、小論文或其他研究。

可重複使用的學習觀念

1. 專題的價值公式

問題 → 嘗試 → 困難 → 查資料／求助 → 修正 → 驗證 → 結果 → 反思

這比只放「最後答案」有價值。

2. 自學內容一定要留下證據

例如： - 新學的軟體 - 新學的數學工具 - 程式碼 - 查過的資料 - 額外讀的文章 - 自己整理的筆記

讓「我有自主學習」不只是口號。

3. 求助本身也是能力

好的求助不是：

老師我不會。

而是：

我想解決 X；我已經試過 A、B；目前卡在 C；想請教 D。

4. 寫信找教授可以用四段式

  1. 我是誰？
  2. 我在研究什麼？
  3. 我已經做了哪些努力？
  4. 我目前具體卡在哪裡？

主動踏出第一步，本身就是學習能力。

5. 找題目的三個來源

  • 多讀文章
  • 觀察生活問題
  • 從既有題目延伸

操作方法：

太大 → 加限制
太小 → 放寬條件
太難 → 簡化版本先做

6. 講述型課程也能做學習歷程

就算沒有科展或專題，也可以整理： - 筆記 - 學習單 - 習題 - 自己的整理 - 延伸學習 - 心得反思

7. 實作型課程優先呈現「做的過程」

包含： - 作品 - 分工 - 版本迭代 - 困難 - 求助 - 修正 - 最後成果

8. 多元表現不只學術競賽

老師舉例： - 校慶園遊會 - 服務學習 - 競賽 - 班遊 - 舞會 - 合唱比賽 - 讀書會 - 學術社團 - 流音社／熱舞社 - 跨校活動 - 國際／友校交流

重點是：

我在活動中負責什麼 → 遇到什麼 → 怎麼合作 → 學到什麼。

9. 團體活動要加「個人角色」

例如： - 總召 - 公關 - 拉贊助 - 教學 - 指揮 - 伴奏 - 企劃

團體企劃書後再補上自己的個人反思，才能看見「你」的貢獻。

10. 反思不要藏在最後

老師建議把心得／反思往前放。

原因很簡單：

如果重要內容放到最後，讀者不一定讀得到。

可直接套用的「專題學習歷程」模板

  1. 一句話摘要：我研究什麼？結果是什麼？
  2. 研究動機：為什麼選這題？
  3. 問題定義
  4. 原本的想法
  5. 遇到的困難
  6. 我查了什麼／問了誰
  7. 方法與工具
  8. 實際成果
  9. 程式／數據／作品等證據
  10. 哪裡失敗、怎麼改
  11. 我額外自學了什麼
  12. 如果繼續做，下一步是什麼
  13. 心得與反思
  14. 與未來科系／興趣的關聯

最後呈現檢查表

  • 內容夠精要嗎？
  • 能用圖片、表格、心智圖取代長文字嗎？
  • 反思有放在容易看到的位置嗎？
  • 能看出我的個性與解題態度嗎？
  • 跟想申請的科系有合理關聯嗎？
  • 版面是否清楚、美觀但不喧賓奪主？
  • 邏輯完整嗎？
  • 有校稿、沒有大量錯字嗎？
  • 平時有留下照片、影片與過程素材嗎？
