一眼看懂：這支影片最重要的 10 點

  1. 中學生獎助計畫的本質不是「比賽」，而是用經費與評審機制幫高中生把研究做下去。

  2. 申請前最好已經有「初步探究」。
    不需要先做完整研究，但至少要能重現現象、掌握主要變因、做過一些小實驗，並有初步資料。

  3. 只讀 reference 不夠。
    初審雖然還不用交完整結果，但若已經有一些實驗或初步數據，研究計畫會更有說服力。

  4. 申請書不是只有題目，要包含完整研究規劃。
    至少要有研究動機、目的／問題、研究設計、參考資料、進度表與經費規劃。

  5. 甘特圖是重要工具。
    半年期研究要能說清楚每個月做什麼，讓評審知道你不是只有想法，而是有可執行計畫。

  6. 經費不要亂寫，也不要寫得太保守。
    影片案例指出可申請的上限高於實際常見核定額；預算要合理、完整、和研究需求直接對應。

  7. 優良作品專輯是申請前最值得讀的資料之一。
    先看同科過去幾年的計畫，就能知道題目深度、寫法、經費與審查期待。

  8. 找教授或實驗室不是遙不可及。
    賴老師鼓勵建中生主動寫信聯絡大學教授；不是每封都會回，但多找幾位，常常就能找到願意給建議的人。

  9. 先做小論文／小型研究，再挑戰半年期專題，是很好的漸進路線。

  10. 耐挫力比一次做得完美更重要。
    影片案例中的學長高一做跳鼠機器人不順利，高二又再申請、繼續改，最後成果與獎項都更好。

這個計畫到底在做什麼？

可以把它理解成：

高中生提出一個可執行的科研計畫 → 書面審查 → 通過後取得研究經費 → 半年持續做研究 → 最後口頭／成果評審

核心不是：

「我要先做到很厲害，才敢申請。」

而是：

「我已經有可行的問題與初步探究，希望透過資源把它做完整。」

申請前要做到什麼程度？

最理想的狀態是：

已完成

  • 找到研究方向
  • 讀過基本 reference
  • 做過初步實驗
  • 確認現象可重現
  • 找出幾個主要變因
  • 有少量初始數據

還不必完成

  • 完整資料
  • 最終結論
  • 全部實驗
  • 正式論文

因為這是一個「研究計畫申請」，不是最後成果競賽。

初審申請書可以固定有這些欄位

  1. 研究動機
  2. 研究目的
  3. 研究問題
  4. 相關文獻
  5. 研究設計
  6. 變因
  7. 初步探究
  8. 研究進度
  9. 甘特圖
  10. 預算
  11. 預期成果
  12. 可能困難與備案

為什麼「初步探究」特別重要？

因為它能證明三件事：

1. 題目真的做得動

不是紙上談兵。

2. 你已經知道主要問題在哪

代表不是只憑想像寫申請書。

3. 後面的半年研究有基礎

評審比較敢把經費給你。

經費怎麼寫？

原則：

每一筆錢都要能回到研究設計。

可以包括： - 材料 - 感測器 - 3D 列印 - 耗材 - 零件 - 實驗用品 - 必要工具

不要： - 為了湊高而亂寫 - 只寫很少，結果後面研究不夠用

影片以當年度案例指出，實際核定常見是萬元等級；但每年規則與核定額可能不同，應以當年度公告為準。

一個很實用的科研時間軸

高一上

  • 找科別
  • 找題目
  • 找老師
  • 閱讀
  • 初步實驗

1–2 月

  • 做初步探究
  • 確認可行性
  • 留初始資料

3–4 月

  • 準備研究計畫
  • 申請中學生獎助計畫
  • 也可準備小論文

5 月前後

  • 書面審查／複審
  • 修正計畫

後續半年

  • 執行研究
  • 固定和老師討論
  • 留版本與數據

10–11 月前後

  • 成果整理
  • 口頭報告
  • 決審

實際月份依年度公告調整。

這個計畫和其他活動怎麼串？

影片把它放在一整條科研路徑裡：

初步探究
→ 小論文
→ 中學生獎助計畫／青培／旺宏等
→ 校內科展
→ 北市科展
→ 全國科展／國際科展

重點是：

一次研究，不需要只用一次。

同一個題目可以持續： - 補資料 - 改方法 - 增加模型 - 做新版本 - 接不同舞臺

找題目最有效的方法

1. 歷屆作品

看： - 校內科展 - 北市科展 - 全國科展 - 中學生獎助計畫優良作品

2. Reference

不用什麼都讀。

目標是找到：

3–10 篇真的和你的題目有關、真的會用到的文章。

3. 找專家

可以找： - 任課老師 - 校內專題老師 - 學長 - 大學教授 - 實驗室學生

4. 物理辯論等現成題庫

有些活動每年都會提供值得研究的題目，也可以當作專題起點。

怎麼寫信找教授？

一封有效的信至少回答：

  1. 我是誰
  2. 我是哪一所學校
  3. 我對哪個領域有興趣
  4. 我目前想做什麼
  5. 我已經讀了什麼／做了什麼
  6. 我卡在哪
  7. 我希望教授提供什麼程度的協助

不要只寫：

教授您好，我想做研究，可以帶我嗎？

跳鼠機器人案例最值得學的地方

這個案例不是因為「機器人很酷」。

而是：

第一代很簡單 → 持續改版 → 高一不順 → 高二再申請 → 繼續改 → 最後成果變好

初版只需要能研究一個基本關係，例如：

彈簧壓縮量 ↔ 跳躍高度

這就已經是一個可量化的研究起點。

可重複使用的學習觀念

1. 先做小實驗，再寫大計畫

避免：

計畫寫得超漂亮，實際根本做不出來。

2. 研究計畫不是承諾「一定成功」

而是：

我知道我要怎麼找答案。

3. Reference 的用途是縮短試錯

不是拿來撐頁數。

4. 一個好老師／好實驗室可以讓你少走很多冤枉路

但另一半仍然是自己的投入。

5. 科研最能練耐挫

因為實驗一定會： - 壞 - 不穩 - 失敗 - 沒差異 - 需要重做

6. 不成功也可以再來一次

高一不完整，高二可以： - 重做 - 改題 - 補資料 - 再申請
