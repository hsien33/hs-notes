一眼看懂：這支影片最重要的 8 點

  1. 學習歷程開頭要先交代「課程脈絡」。
    摘要與目錄不只是排版，而是要讓審查者迅速知道：這份作品來自哪一門課、哪一個單元、做了什麼任務，以及為什麼會產生這份作品。

  2. 作品與課程之間要建立清楚的因果鏈。
    最理想的邏輯是：

    課程／單元 → 學習任務 → 產出作品 → 回饋修正 → 能力成長 → 反思

  3. 一般課堂作業也能成為有份量的學習歷程。
    讀書心得、人物傳記報告、國寫作文，都是學生本來就會有的作業；不一定要另做很華麗的專題，重點是怎麼整理與呈現。

  4. 一份作品最好能同時呈現多種能力證據。
    例如人物傳記閱讀心得，可同時看見簡報設計、閱讀理解、跨媒材比較、寫作與思辨能力。

  5. 不要只寫內容摘要，要盡早放入自己的觀點。
    如果前面大半篇幅都只是重述內容，自己的分析與延伸議題太晚才出現，作品就會失焦。

  6. 同儕回饋、老師評語都可以成為學習證據。
    把別人的意見留下，再呈現自己如何回應、修正與反思，比只放最終作品更完整。

  7. 最有說服力的是 Before → After。
    初稿、修改稿、老師意見、自己的省思全部放在一起，能讓審查者直接看到進步。

  8. 不要執著呈現「100 分作品」，70→95 的成長更有價值。
    從生澀到純熟的學習軌跡，往往比一開始就看起來完美，更能證明真實學習。

影片內容重點

  • 劉子維老師以楊宗勳學長高一上國文科學習歷程為案例。
  • 作品一開始用摘要與目錄說明標題、課程背景、作品內容與課程的關聯。
  • 這種設計能讓審查者快速理解「為什麼會有這份作品」以及作品的核心。
  • 第一部分是人物傳記讀書心得報告，源自高一國文「世說新語選讀」課程，希望學生找到人格典範並思考生命態度。
  • 學生需選人物傳記閱讀、製作簡報、進行 8–10 分鐘口頭報告，臺下同學提供回饋，再撰寫閱讀心得。
  • 楊宗勳學長以《愛的萬物論》為題，作品呈現簡報、閱讀與寫作等能力。
  • 在閱讀方面，不只讀文本，也比較改編電影，進一步延伸到婚姻與家庭議題。
  • 在寫作方面，格式清楚、段落完整，也能延伸討論當代家庭問題。
  • 老師也指出作品缺點：簡報圖片多但文字資訊略少；書面心得前半段敘述過多，個人觀點與延伸議題出現得太晚。
  • 第二部分是國寫情意題課堂演練，學生在限時情境完成初稿，再打字修改。
  • 學習歷程中同時放初稿、修改稿、老師評語與個人省思，形成明顯的 Before／After。
  • 老師強調：學習歷程不必只放完美成果，從 70 分進步到 95 分的軌跡更能打動審查者。
  • 結尾再用「閱讀的意義」「學期省思與期許」回顧整學期，讓整份檔案有頭有尾、脈絡完整。

可重複使用的學習觀念

1. 學習歷程先回答「這份作品為什麼存在？」

一開始就應清楚交代： - 哪一門課？ - 哪一個單元？ - 老師給了什麼任務？ - 為什麼要做？ - 最後產生什麼作品？

核心觀念：先建立脈絡，再展示成果。

2. 建立「課程 → 任務 → 成果 → 成長」因果鏈

不要只把一堆檔案堆在一起。

理想結構：

課程背景 → 任務要求 → 我的作品 → 收到的回饋 → 我的修改 → 我學到什麼

這能讓讀者知道每一頁存在的理由。

3. 普通作業也可以變成好作品

不必為了學習歷程硬做一個「特別企劃」。

真正有價值的是：

把原本就做過的作業，整理出它的學習意義、能力證據與成長過程。

4. 摘要不是越多越好，觀點要提早出現

如果作品前 2/3 都是在重述書本、影片或資料，真正自己的想法只剩最後一小段，會降低作品辨識度。

可以改成：

必要背景 → 我的觀察 → 我的分析 → 證據 → 延伸問題

5. 一份作品要盡量呈現「能力證據」

不要只寫「我提升了閱讀能力」。

要讓人看得到： - 簡報頁面 - 閱讀比較 - 原始文章 - 老師批改 - 同儕回饋 - 修改前後 - 自己的分析

能力要有證據，不只是一句自我宣稱。

6. 同儕／教師回饋要轉成下一步

回饋本身不是重點。

真正有價值的是：

別人說了什麼 → 我怎麼理解 → 我改了什麼 → 下一次如何避免／做得更好

7. Before / After 是非常強的呈現方式

例如： - 初稿 vs. 修正版 - 第一次簡報 vs. 第二次簡報 - 老師批改前 vs. 訂正後 - 一開始的觀點 vs. 最後的反思

這能把「我有進步」變成可看見的證據。

8. 70→95 比只放 100 分更能呈現學習

學習歷程的目的不是證明自己從來不犯錯。

更值得呈現的是：

我原本哪裡不好 → 收到什麼回饋 → 怎麼修改 → 最後變好多少

9. 結尾要做「整合式反思」

最後不要只寫「謝謝老師」。

可以固定整理： 1. 我重新理解了什麼？ 2. 我最明顯的能力成長是什麼？ 3. 我仍有哪些不足？ 4. 下一次要怎麼改？ 5. 這件事對未來有什麼影響？

10. 好的學習歷程本身就是資訊設計

老師反覆強調的其實包含： - 定位明確 - 標題清楚 - 摘要簡潔 - 目錄好找 - 有頭有尾 - 邏輯連續 - 不讓讀者自己猜重點

可直接套用的學習歷程模板

  1. 一句話標題：這份作品是什麼？
  2. 課程背景：哪一門課、哪個單元？
  3. 任務目的：老師希望我學什麼？
  4. 作品成果：我實際做了什麼？
  5. 能力證據：哪幾頁可以證明我的能力？
  6. 回饋：老師／同學指出了什麼？
  7. Before → After：我改了哪些地方？
  8. 具體成長：從哪裡進步到哪裡？
  9. 不足與反思：還可以怎麼更好？
  10. 下一步：未來如何延伸？

本片一句話濃縮

📝 展開完整校正版逐字稿

大家好,我是建中國文科劉子維老師。很高興能透過這支影片分享怎麼樣製作課堂活動成果這個類型的想法。今天要跟大家推薦的是楊宗勳學長的作品,是他在高一上學期針對國文課的一個學習歷程檔案。

透過螢幕我們可以看到宗勳學長這一份課堂活動成果。開頭的摘要以及目錄,先秀出簡明清楚的標題以及課程脈絡的說明。向審查教授簡介一下這份作品包含哪些項目,清楚呈現的作品與課程的關聯性。

作為整份作品的精華摘要。可以讓審查教授對主題有一個初步認識,能更快掌握到這份作品的核心,明白作者是因為配合什麼課程或者單元內容而去閱讀一本書、撰寫一篇作文,建立起課程與作品的因果脈絡邏輯。這是宗勳學長作品的一大亮點。

第一部分我們看到讀書心得的報告。當時是高一上學期的國文課。我們的課本裡面有一課是世說新語選讀。當時候老師期許高一新鮮人能找到學習的人格典範,協助他們建立起自己的生命態度。所以在課堂上推出這個人物傳記的報告。

規定每位同學必須選定一部人物傳記,用心閱讀後製作一份簡報,在課堂上進行8到10分鐘口頭報告。而臺下同學必須要用心參與,並在回饋表單上面提供鼓勵和建議,建立起同儕回饋的機制。課後必須依照中學生網站的格式規範。

撰寫閱讀心得寫作一篇,並參加中學生閱讀心得寫作比賽。老師期待這個活動能讓同學找到生命依循的方向,同時提升同學的語文素養能力,包括三力、閱讀力、簡報力以及寫作力。宗勳學長的這份《愛的萬物論》，縱觀史蒂芬・霍金這個作品，基本上完成了這項課堂活動。我們首先看到學長展現出他的簡報力，在版面設計以及顏色搭配上大致得宜。其次在閱讀力方面，因為學長同時看過《愛的萬物論》以及改編的電影。

能夠掌握文字跟影視之間情節的異同比較,延伸出更進一步的婚姻議題討論,表現出精準而完整的閱讀力。第三,在寫作方面,學長的作品完全符合中學生網站讀書心得寫作比賽的格式規範,清楚交代了自己選書的原因。

全文段落分明、表達精準,在討論議題方面能進一步地探討當代家庭離婚的問題,展現出高中生的思辨能力。最後,學長跟我們分享了同學給他的正面的以及可以改進空間的回饋。學長的報告後的收穫與省思,誠懇而認真。

能夠充分地說服教授,這是一份用心投入的作品。美中不足的是,學長的簡報圖片豐富,但是文字訊息相對簡略了一點。在書面心得方面,篇幅非常的長,但是前半段純敘述的文字佔掉太多版面。

到作品超過三分之二的地方才真的有個人的想法觀點,延伸議題、呈現,有太晚聚焦的問題。這部分書寫重點的拿捏,也是往後可以再進步的地方。不過整體而言,學長的閱讀心得報告歷程已經相當完整具體了。

接下來我們來看到第二部分是學長分享的國寫情意題課堂演練的部分。這個是國文課必須演練的大考科目之一。老師讓同學們在課堂上實際地演練模擬考場的情境,要在時間內完成寫作。期待同學能透過這樣的演練

寫作篇幅和時間掌控都漸入佳境。宗勳學長在簡單的摘要介紹之後秀出了他課堂上完成的初稿以及電腦打字之後修改後的作品也把老師的評語意見以及他個人在寫作前後的收穫與省思都呈現出來。

讓教授具體的看見before和after的對照張力是一份學習歷程脈絡完整的作品。我們可以發現到我們不需要執著在呈現100分完美的作品而是應該呈現出可能從70分到最後邁向95分這一條從生澀

到純熟這個學習與進步的歷程軌跡更能夠打動我們的審查教授喔!最後,在結語的部分,學長分別就我所體認到閱讀的意義以及學期、省思和期許兩個標題去回顧一下整個學期國文課的學思歷程。

綱舉目張,簡明扼要,有畫龍點睛的效果。整份的學習歷程檔案,定位明確,標題清楚,有頭有尾,脈絡清晰,真是一份有份量的作品。宗勳學長當年製作這份學習歷程檔案,正和各位高一同學是一樣的學習階段。

我們所分享的讀書心得報告以及國寫作文,都是各位手邊一定會有的作業類型。期待各位心動不如馬上行動,在這個學期末也產出一份讓我們驚豔的作品吧。接下來。

我們歡迎楊宗勳學長重磅回歸,跟我們聊一聊他當年的學習歷程吧!
