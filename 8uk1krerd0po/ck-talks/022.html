一眼看懂：這支影片最重要的 10 點

  1. 青培不是只有科學班、數理班能參加，普通班也可以。
  2. 青培最適合已經有研究題目、打算往 TISF／科展長期做下去的學生。
  3. 青培會提供研究經費、教授輔導與多次研習／報告機會。
  4. 沒有大學指導教授也不是問題，科教館可協助媒合相關領域教授。
  5. 初審看研究計畫書；複審看你能不能把研究說清楚、回答教授問題。
  6. 計畫書重點不是保證一定成功，而是證明你已經把研究想清楚、能執行。
  7. 複審不用假裝什麼都懂；誠懇、能傾聽、能回答、能承認不知道，反而更重要。
  8. 研習營的價值在於反覆報告、被不同教授問、持續改研究與表達。
  9. 參加青培後通常要依規定銜接臺灣國際科展（TISF），所以不是只拿補助就結束。
  10. 真正的成長來自版本迭代：計畫書 → 進度報告 → 最終報告 → TISF 作品。

青培到底在幫什麼？

可以把它理解成：

高中專題研究的「加速器」

如果你已經有： - 題目 - 研究夥伴 - 初步方向 - 想往科展／TISF 做深

青培會再補上： - 研究經費 - 教授媒合 - 研究輔導 - 研習營 - 報告訓練 - 作品修改 - TISF 銜接

青培適合誰？

適合

  • 已經有題目
  • 願意投入半年以上
  • 想做真正研究
  • 想參加 TISF／科展
  • 願意反覆修改

不太適合

  • 只想拿補助
  • 還完全沒有題目
  • 不想定期報告
  • 不願意持續改研究
  • 只想做一次就結束

初審：研究計畫書怎麼寫？

陳泓菖學長強調：

讓教授感覺「你真的想過，而且做得到」。

可以包含：

  1. 研究動機
  2. 研究問題
  3. 文獻背景
  4. 方法
  5. 實驗設計
  6. 預期成果
  7. 時程
  8. 經費
  9. 困難與備案
  10. 未來延伸

計畫書最重要的不是「保證成功」

真正要傳達的是：

我已經查過資料
→ 我知道問題在哪
→ 我知道怎麼做
→ 我知道可能會失敗在哪
→ 即使失敗，我也有下一步

複審怎麼準備？

複審通常是：

簡報＋教授提問

教授不一定完全熟你的題目。

所以你要做兩件事：

1. 讓陌生人聽懂

不要一開始就丟大量專有名詞。

先說： - 問題是什麼 - 為什麼值得研究 - 你要怎麼驗證

2. 被追問時不要慌

可以： - 先確認問題 - 說出目前理解 - 說明不確定處 - 回答你下一步怎麼查證

青培能提供什麼？

影片提到的核心資源有：

1. 研究經費

可支應研究材料與實驗需要。

2. 指導教授媒合

沒有大學教授也可以透過計畫協助接洽。

3. 教授輔導

教授不只是掛名，而是可能協助： - 方法 - 實驗室資源 - 報告 - 研究方向 - 研究瓶頸

4. 多次研習營

持續追蹤進度，並練報告。

研習營真正有價值的地方

研習營不是「再被考一次」。

真正功能是：

讓不同背景的人聽你的研究，告訴你哪裡講不懂、哪裡邏輯不清楚。

熟悉你的指導老師可能看不出： - 哪些概念跳太快 - 哪些圖說不清楚 - 哪些結論一般人看不懂

陌生教授反而能抓出問題。

版本迭代是青培最值得學的流程

可以把研究文件想成：

計畫書
→ 進度報告
→ 中期版本
→ 最終報告
→ 海報
→ TISF 研究報告

不是每次重寫一份，而是：

同一個研究持續變成熟。

「延續性作品」要注意

如果題目之前已經參加過其他科展或計畫：

一定要確認： - 哪些內容是舊的 - 哪些是新的 - 新增哪些實驗 - 新增哪些數據 - 新增哪些結論

避免：

同一份作品原封不動重複投稿。

青培和其他獎助計畫的關係

有些計畫申請期會重疊。

可能出現：

兩邊都申請 → 兩邊都入選 → 最後必須擇一

所以要事先看簡章。

一個很重要的提醒：時間看學校公告

影片特別提醒：

不要只看中央簡章日期，校內設備組通常會更早收件。

因為： - 學校還要審核 - 整理 - 團體送件

所以真正 deadline 是：

校內 deadline

陳泓菖學長案例最值得學什麼？

1. 普通班也能做

不必等進數理班／科學班。

2. 題目從自己熟悉的興趣開始

他本身從程式與工程方向切入。

3. 初期也不是什麼都準備好

一開始甚至還沒有大學教授。

4. 寫計畫書本身就是一次思考訓練

逼自己把： - 問題 - 方法 - 步驟 - 時程 - 預期結果

全部說清楚。

5. 教授資源會放大研究品質

有實驗室、設備與研究方法指導後，作品進步會非常明顯。

可重複使用的學習觀念

1. 研究計畫書不是作文

每一段都要回答：

這段如何支持「這個研究可做」？

2. 複審不是背稿

真正要練： - 解釋 - 應變 - 傾聽 - 回答 - 誠實

3. 陌生人看不懂，就是溝通問題

不是別人笨。

4. 長期研究一定要版本化

建議保存： - v1 - v2 - v3

並記錄每版修改原因。

5. 找教授不需要等到「很厲害」

先有： - 題目 - 基本資料 - 初步嘗試

就可以開始找。

6. 真正的科研成長來自被問問題

每次教授問不出來的地方，就是下一個研究 TODO。

可直接套用的「青培申請清單」

研究面

  • [ ] 題目明確
  • [ ] 有研究問題
  • [ ] 有基本 reference
  • [ ] 有初步方法
  • [ ] 最好已有少量初步結果

計畫書

  • [ ] 動機
  • [ ] 問題
  • [ ] 文獻
  • [ ] 方法
  • [ ] 時程
  • [ ] 預算
  • [ ] 預期成果
  • [ ] 風險與備案

複審

  • [ ] 3–5 分鐘說清楚研究
  • [ ] 圖比字多
  • [ ] 預想 10 個教授問題
  • [ ] 找不熟題目的人試聽
  • [ ] 練習承認「我目前還不知道」

通過後

  • [ ] 固定更新進度
  • [ ] 保存每版報告
  • [ ] 把教授建議變 TODO
  • [ ] 提早準備 TISF 格式
  • [ ] 每次研習營後立即修改
